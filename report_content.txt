по производственной практике
по теме: «Разработка PWA-приложения для организации проектной деятельности в школе»

1. Введение

В период производственной практики была выполнена разработка учебного веб-приложения формата PWA для организации проектной деятельности учащихся в школе.
Актуальность темы обусловлена необходимостью цифровизации учебного процесса, упрощения взаимодействия между учителем и учеником, а также повышения прозрачности контроля выполнения проектных задач.

Разрабатываемая система ориентирована на две роли пользователей:
- учитель;
- ученик.

Приложение предоставляет базовый, но функционально завершенный MVP-уровень: регистрацию и авторизацию пользователей, управление проектами, назначение участников, постановку задач, контроль прогресса, ведение профиля пользователя и адаптивный интерфейс.

2. Цель и задачи практики

Цель практики:
Разработать и протестировать PWA-приложение для поддержки школьной проектной деятельности с использованием современных веб-технологий.

Задачи практики:
1) Изучить предметную область и сформулировать требования к системе.
2) Спроектировать структуру данных и архитектуру приложения.
3) Реализовать интерфейс и бизнес-логику приложения.
4) Настроить аутентификацию и хранение данных в Firebase.
5) Реализовать ролевую модель доступа (учитель/ученик).
6) Обеспечить адаптивность интерфейса и признаки PWA.
7) Провести тестирование и подготовить демонстрационные данные.
8) Подготовить итоговую документацию по выполненным работам.

3. Краткая характеристика выполненного проекта

Разработано приложение PAX — школьная платформа управления проектами.

Основные возможности:
- регистрация и вход по email/password;
- выбор роли пользователя при регистрации;
- создание проектов учителем;
- фильтрация проектов по статусу, классу и параллели;
- просмотр проекта и его задач;
- назначение исполнителей задач;
- контроль статусов выполнения задач;
- отображение прогресса проекта;
- профиль пользователя (фото, школа, класс, параллель);
- мобильная адаптация и PWA-функциональность.

Технологический стек:
- React + Vite;
- React Router;
- Firebase Authentication;
- Cloud Firestore;
- vite-plugin-pwa;
- CSS Modules.

4. Содержание дневника практики (пример заполнения)

1) Аналитический этап — анализ предметной области, определение требований к системе.
Результат: сформирован перечень функций MVP.

2) Проектирование — определены роли, маршруты, структура страниц и коллекций Firestore.
Результат: подготовлена структура проекта.

3) Настройка среды — инициализация проекта на React + Vite, подключение зависимостей.
Результат: рабочий каркас приложения.

4) Firebase-интеграция — подключены Authentication и Firestore, настроены переменные окружения.
Результат: реализована серверная часть хранения данных.

5) Авторизация — реализованы страницы входа/регистрации и контекст авторизации.
Результат: пользователь может входить и регистрироваться.

6) Роли и доступ — настроены защищенные маршруты и ограничения по ролям.
Результат: ученики и учителя видят разный функционал.

7) Проекты — реализовано создание, просмотр и фильтрация проектов.
Результат: учитель может управлять проектами.

8) Задачи — реализована постановка задач и смена статусов.
Результат: отслеживается выполнение задач по проекту.

9) Профиль — добавлены поля школы/класса/параллели и фото пользователя.
Результат: расширена персонализация аккаунта.

10) UI/UX и адаптив — реализовано мобильное меню, улучшены карточки и кнопки.
Результат: интерфейс пригоден для мобильных устройств.

11) PWA — настроены manifest, service worker, установка приложения.
Результат: приложение доступно как PWA.

12) Тестирование и наполнение — подготовлены seed-скрипты для пользователей, проектов и задач.
Результат: база заполнена тестовыми данными.

7. Тестирование и наполнение базы

Для демонстрации реализованы seed-скрипты:
- seed-users.js — массовое создание пользователей;
- seed-projects.js — создание проектов, задач и назначений.

Проведены проверки:
- корректность авторизации;
- ролевые ограничения доступа;
- корректность фильтрации проектов;
- корректность добавления и обновления задач;
- адаптивность интерфейса на мобильных экранах.

8. Итоги практики

В результате практики разработано работоспособное PWA-приложение, обеспечивающее основные процессы школьной проектной деятельности:
- управление проектами;
- распределение участников;
- постановка и контроль задач;
- ролевой доступ;
- адаптивный интерфейс.

Поставленная цель достигнута, задачи выполнены в полном объеме.
Разработанный продукт может использоваться как учебный прототип и основа для дальнейшего развития.

9. Заключение

Практика позволила закрепить навыки проектирования и разработки веб-приложений полного цикла: от анализа требований до финального тестирования и подготовки демонстрационных данных.
Полученный результат соответствует теме практики и может быть представлен в рамках учебной аттестации и защиты.
