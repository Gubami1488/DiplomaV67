# PAX

Учебный веб-проект для дипломной работы на тему: "PWA-платформа для организации проектной деятельности учащихся в школе".

## Технологии

- React + Vite
- React Router
- Firebase Authentication
- Cloud Firestore
- vite-plugin-pwa
- JavaScript без TypeScript
- CSS Modules

## Основные возможности

- регистрация и вход по email/password
- выбор роли при регистрации: учитель или ученик
- хранение профиля пользователя в Firestore
- создание проектов учителем
- просмотр списка проектов и фильтрация
- назначение участников проекта
- создание задач внутри проекта
- смена статуса задач учеником только для своих задач
- просмотр прогресса по задачам
- профиль пользователя и страница "Мои проекты"
- установка на телефон или компьютер, офлайн-доступ к основным ресурсам

## Структура Firestore

Коллекции:

- `users`: `uid`, `name`, `email`, `role`, `createdAt`
- `projects`: `title`, `description`, `theme`, `deadline`, `status`, `teacherId`, `participants`, `createdAt`
- `tasks`: `projectId`, `title`, `description`, `deadline`, `status`, `assigneeId`, `createdAt`

## Запуск проекта

1. Установить зависимости:

```bash
npm install
```

2. Создать файл `.env` на основе `.env.example`.

3. Запустить проект локально:

```bash
npm run dev
```

4. Открыть адрес из консоли Vite, обычно `http://localhost:5173`.

## Настройка Firebase

Нужно создать проект Firebase и включить:

- Authentication -> Email/Password
- Firestore Database

Затем заполнить переменные окружения в `.env`.

## Рекомендации по Firestore Rules

Для демонстрационного учебного проекта правила доступа лучше настроить отдельно. На защите можно использовать безопасные правила, в которых:

- пользователь читает свой профиль
- учитель создаёт проекты и задачи
- ученик меняет только свои задачи

## Сборка

```bash
npm run build
```

## Примечание по офлайн-режиму

Приложение кэширует статические ресурсы и может открываться без сети после первого посещения. Операции Firebase в офлайн-режиме зависят от доступности сети и политики кэширования браузера.
